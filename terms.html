1. Alcance

Estos términos describen el uso de Creator Finder, desarrollado por XOTOX STUDIO. La aplicación se utiliza para descubrir creadores y gestionar campañas de outreach relacionadas con los videojuegos del desarrollador.

2. Naturaleza privada y acceso

Creator Finder es actualmente una herramienta local, privada y de uso interno. No se ofrece como servicio público, no permite crear cuentas y no existe un derecho general de acceso. La existencia de este sitio informativo no convierte la aplicación en un servicio disponible al público.

3. Uso apropiado

El usuario es responsable de utilizar Creator Finder de forma lícita, razonable y coherente con las políticas de los servicios externos. No debe utilizarse para:

  • spam o comunicaciones masivas indiscriminadas;
  • obtener, inferir o intentar acceder a información privada;
  • ignorar solicitudes de no contactar o eludir controles de deduplicación;
  • evitar, sortear o manipular cuotas, restricciones o medidas técnicas;
  • realizar actividades contrarias a las condiciones de Google, YouTube, Gmail u otros terceros;
  • presentar evaluaciones internas como métricas oficiales proporcionadas por YouTube.

4. Servicios externos

Creator Finder usa YouTube Data API v3 mediante una API key y puede usar Gmail mediante autorización incremental: gmail.compose para borradores/envío y, solo si se activa la detección de respuestas, gmail.readonly. Los detalles figuran en la Política de Privacidad. Su uso está sujeto a los Términos de YouTube, los Términos de YouTube API Services, las Políticas para desarrolladores de YouTube API Services, las condiciones de Google APIs y las políticas específicas de Google Workspace.

Sin afiliación.Creator Finder no es un producto oficial de Google ni de YouTube y no está afiliado, aprobado, verificado, respaldado, patrocinado ni certificado por dichas entidades.

5. Comunicaciones y contactos

Las vías de contacto deben ser públicas, apropiadas y estar asociadas al creador o a su representante. El usuario debe revisar el contexto y el contenido antes de contactar. Cualquier envío mediante Gmail requiere una acción explícita de aprobación.

Las solicitudes de no contactar deben respetarse. Creator Finder incluye estados y controles orientados a evitar duplicados, pero la responsabilidad final de cada comunicación corresponde al usuario.

6. Disponibilidad y cambios

Creator Finder se proporciona para uso interno en su estado actual. No se garantiza que la aplicación o las APIs externas estén disponibles permanentemente, funcionen sin interrupciones o mantengan las mismas funciones, cuotas o condiciones. XOTOX STUDIO puede modificar o dejar de utilizar la herramienta.

Estos términos pueden actualizarse si cambian la aplicación, las políticas externas o el modo de uso. La fecha más reciente se mostrará al principio de esta página.

7. Propiedad e identidad

Creator Finder y su identidad pertenecen a XOTOX STUDIO. YouTube, Google, Gmail y sus marcas pertenecen a sus respectivos titulares. Las referencias a esos servicios describen integraciones técnicas y no implican relación comercial o respaldo.
